Необходимо разработать одностраничное приложение TaskFlow для управления задачами.

1. Управление задачами
Каждая задача содержит название, описание, приоритет и статус.
Пользователь должен иметь возможность:
создавать задачи;
редактировать их;
удалять их;
менять статус между «Новая», «В работе» и «Выполнена»;
выбирать приоритет: низкий, средний или высокий;
видеть общее количество задач и число завершённых задач.
Название задачи обязательно. Пустые задачи добавлять нельзя.

2. Поиск и фильтрация
Добавить поиск по названию, фильтрацию по статусу и приоритету, а также возможность сбрасывать фильтры.
Фильтры должны работать одновременно. Предыдущее значение поискового запроса необходимо сохранять с помощью useRef.

3. Общие настройки через Context
Создать AppContext и Provider, предоставляющие:
тему оформления;
функцию переключения темы;
общий счётчик действий пользователя.
Тема должна переключаться между светлой и тёмной. Настройки должны быть доступны разным компонентам без передачи props через всю цепочку вложенности.

4. Статистика
На экране должны отображаться общее количество задач, количество выполненных задач, количество задач в работе, процент выполнения.
Все показатели должны автоматически обновляться при изменении задач.
